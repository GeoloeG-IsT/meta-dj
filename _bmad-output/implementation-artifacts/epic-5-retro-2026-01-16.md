## What Didn't Go Well

### Integration Testing Gap

Story 5.5 revealed that loop playback boundary enforcement was completely missing from the codebase. Unit tests existed for:
- ✅ Loop creation UI
- ✅ Loop database persistence
- ✅ Loop waveform rendering

But NO test verified: "When playback reaches loop out-point, does it jump back to in-point?"

**Root Cause:** Unit tests on isolated functions don't catch integration gaps.

### Epic 2 Agreement Not Applied

The team agreed in Epic 2 to "verify end-to-end feature path before marking tasks complete" but this wasn't consistently applied. The loop playback gap shipped from Epic 2 and wasn't discovered until Epic 5's explicit "Fix Loop Creation" story.

### File List Documentation Incomplete

3 out of 6 stories (50%) had incomplete File List documentation:
- Story 5.2: Included non-source files
- Story 5.5: Some review items marked INFO for future
- Story 5.6: 3 files changed but not documented

## Key Insights

1. **Code reviews are our safety net, but we're catching things late** - 83% of stories needed fixes
2. **Unit tests don't catch integration gaps** - Loop feature was "tested" but broken end-to-end
3. **Team agreements need enforcement mechanisms** - Just agreeing isn't enough
4. **Documentation discipline prevents debugging pain** - Incomplete File Lists slow down troubleshooting
5. **UI cleanup has compound benefits** - Removing debug panels improved focus and professionalism
